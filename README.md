# Validate_Kalman_Filter

# 设计初衷

对于视觉自瞄来说，验证`ekf`模型以及参数都是一个比较麻烦的事情，需要依赖于电控联调来验证模型的正确性以及参数的可收敛性。并且对于整个自瞄系统来说，会比较严重地受到检测模型精度的影响。于是为了解决这个问题，我就设计了这个工具，通过给予完美的观测值验证不同建模的`ekf`的正确性。

---

# 设计思路

> ***该项目主要分为以下几个部分***：
> - ***运动状态生成器***
> - ***ekf拟合器***
> - ***拟合效果验证器***

## 运动状态生成器

这个部分主要是用于模拟以下常见的几种运动状态：

### 自旋小陀螺部分

- ***正弦函数***：通过一个或者多个形式为`Asin(wt+phi) + x`正弦函数来表示物体运动速度，并通过微分求加速度，积分求转动历史总角度来得到自旋观测值状态

### 纯平移运动部分

- ***两点间平移运动***：通过指定两点位置，一次往返时间来指定来回运动的特性，期间速度使用四分之一个周期余弦函数来约束速度，达到速度均匀的目的
- ***随机平移运动***：纯随机运动，通过指定随机的种子以及整个过程中的最大速度，来达到在一个空间内随机运动的目的


通过修改在`configs`中的设置，来定制自己需要建立拟合的场景，向`ekf`拟合器输出观测值，以及可供他对比的实际运动状态
