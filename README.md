# Validate_Kalman_Filter

# 设计初衷

对于视觉自瞄来说，验证`ekf`模型以及参数都是一个比较麻烦的事情，需要依赖于电控联调来验证模型的正确性以及参数的可收敛性。于是为了解决这个问题，我就设计了这个工具，高度可自定义化地验证不同建模的`ekf`的正确性。

---

# 设计思路

> ***该项目主要分为以下几个部分***：
> - ***运动状态生成器***
> - ***ekf拟合器***
> - ***拟合效果验证器***

## 运动状态生成器

这个部分主要是用于模拟以下常见的几种运动状态：

### 纯小陀螺部分

- ***正弦小陀螺***
- ***匀速小陀螺***
- ***随机数小陀螺***

### 纯平移运动部分

- ***匀速平移运动***
- ***变速平移运动***

### 组合运动

- ***正弦小陀螺 + 匀速平移运动***
- ***正弦小陀螺 + 变速平移运动***
- ***匀速小陀螺 + 匀速平移运动***
- ***匀速小陀螺 + 变速平移运动***
- ***随机数小陀螺 + 匀速平移运动***
- ***随机数小陀螺 + 变速平移运动***

通过修改在`configs`中的设置，来定制自己需要建立拟合的场景，向`ekf`拟合器输出观测值，以及可供他对比的实际运动状态
